Packing and Claiming Tracker Generator

Upload an orders export. This tool pulls the customer/shipping details, sums the per-item Outstanding Balance (values separated by |) into a Refund total, and builds a clean worksheet sorted alphabetically by email.

1 Upload orders export

Click to choose a file or drag it here
.xls, .xlsx, or .csv — exported orders file

2 Build the sheet

Pulls Order Number, Customer → Customer Name, Email, Mobile, Shipping Method, Full Address, Landmark, and Notes as-is. Item Name is split on | so each item gets its own row, lined up with its matching # of Allocation value — items with 0 allocation are left out. Sums Outstanding Balance → Refund per order. Rows are sorted A–Z by email. Order-level fields and Refund appear only on an order's first item row; when the same email appears on multiple orders, a TOTAL REFUND column shows the combined Refund for that email on the very first row only (nothing is merged — the extra rows just stay blank in those columns). Orders whose email's TOTAL REFUND is not negative (zero or positive) get a light red row highlight.
